# Guia da operadora

Este guia acompanha o comportamento de `develop`, conferido em 21/10/2026. Isso não confirma que a mesma versão já esteja em produção. Se sua tela for diferente, peça à administradora técnica que confira a versão da instalação antes de seguir uma ação.

Você pode preparar um formulário que apenas salva respostas ou que também gera um plano em PDF. “Lead”, quando aparecer na tela, significa a participante que respondeu. Os nomes entre aspas são os textos usados no painel.

## O que cada ação confirma

| Ação ou estado | O que significa |
| --- | --- |
| Rascunho salvo | As alterações foram aceitas para revisão; a versão pública continua igual. |
| Versão publicada | Os próximos envios usam essa definição, se o formulário estiver ativo. |
| Respostas salvas | O sistema recebeu o envio. Na captura, não haverá plano nem PDF. |
| Geração concluída | O processamento terminou; confira a disponibilidade do arquivo atual. |
| Acesso liberado | A participante tem autorização para a tentativa indicada; isso não confirma envio ou leitura. |
| Envio confirmado | O transporte para uma integração foi confirmado; isso não comprova atendimento ou leitura humana. |

O painel oferece campos para muitas edições, mas também mantém JSON, fórmulas e templates. JSON é um texto estruturado, com nomes e valores; template é o modelo que monta uma página ou documento. Você não precisa aprender programação para acompanhar respostas. Para mudar estruturas que não entende, trabalhe com a administradora técnica.
