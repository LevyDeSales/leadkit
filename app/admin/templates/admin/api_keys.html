Chaves de API

Uma chave deixa um script ou um agente chamar a API do admin no lugar de uma pessoa logada. Cada chave tem um nome e um papel: leitura só consulta, e total faz tudo o que o admin logado faz. Tudo o que uma chave faz fica na auditoria com o nome dela, chave:nome.

A API fica em /admin/api/v1. Para testar uma chave nova, chame GET /admin/api/v1/me com ela no cabeçalho Authorization. A referência da API descreve cada operação e deixa testá-la com a chave. Para usar uma chave no Claude, siga o passo a passo de Configurar o MCP.
